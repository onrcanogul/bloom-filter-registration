Bloom filter ile kullanıcı kaydı

Kullanıcı adı müsaitliği önce bellekteki Guava Bloom filter'a sorulur. Filtre "kesinlikle yok" derse veritabanına hiç gidilmez; "olabilir" derse veritabanı doğrular.

Kayıtlı kullanıcı–
Bloom filter boyutu–
Güncel yanlış pozitif olasılığı–
Atlanan DB sorgusu–
DB sorgusu / yanlış pozitif–

Kayıt formu

Bloom filter → Veritabanı → Sonuç

Yazmaya başlayın; her tuşta müsaitlik kontrol edilir.
